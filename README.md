# 한승우 | 게임 클라이언트 · 백엔드 개발

Unreal Engine·C++ 기반 콘텐츠부터 서버 연동과 배포까지 개발해 왔습니다. 아래 프로젝트에서 담당 구현과 소스코드를 확인하실 수 있습니다.

## 게임 개발 대표 프로젝트

### Stage On — UE5 실시간 가상공연장 플랫폼

버추얼 공연자와 관객이 실시간으로 상호작용하는 가상 공연장입니다.

- **담당 구현:** HTTP 다운로드·MediaPlayer 기반 멀티클라이언트 음원 재생, 공연 상태 처리, Actor Component 리팩터링
- **기술:** Unreal Engine 5 · C++ · Blueprint · RPC
- **성과:** 메타버스 아카데미 3기 최종성과공유회 대상·과학기술정보통신부 장관상

**[핵심 구현과 코드 보기](https://github.com/H-SeungWoo/VirtualIdol#readme)** · **[실행 영상 보기](https://www.youtube.com/watch?v=JKt8BfGZm_k)**

### It Takes Two 모작 — 공구통 보스전

협동 플랫포머 게임의 공구통 보스전을 모작한 팀 프로젝트입니다.

- **담당 구현:** 못 발사·박힘·회수 시스템, FSM 기반 상태 관리, 객체 재사용, 회수 객체와 보관 배열의 불일치 해결
- **기술:** Unreal Engine 5 · C++ · Blueprint · FSM · Object Pooling

**[핵심 구현과 코드 보기](https://github.com/H-SeungWoo/ItTakesTwo_copy#readme)** · **[실행 영상 보기](https://www.youtube.com/watch?v=Ag4aGCEbZQQ)**

### FIVE ALIBIS — AI 페르소나 기반 웹 추리 게임

5명의 용의자를 심문하고 진술과 기록을 비교해 가설을 입증하는 2인 팀 프로젝트입니다.

- **담당 역할:** 핵심 진행 규칙·UI/UX 설계, Seed 기반 사건 생성 기능 개발 참여, 게임 엔진과 런타임 AI의 책임 범위 공동 설계
- **AI 활용:** 기대 동작·작업 범위·검증 기준을 구체화해 AI 코딩 에이전트와 개발
- **저장소:** 🔒 **비공개 저장소 (Private)**

## 백엔드 대표 프로젝트

### AssetBox — 3D 에셋 공유·관리 서비스

Unity·Unreal 개발자와 테크니컬 아티스트가 에셋을 공유하고 제작을 요청하는 서비스입니다.

- **담당 구현:** ZIP 경로·용량 검증, AWS S3 업로드와 실패 시 보상 삭제, 삭제 유예·정리 배치
- **협업:** TA 수강생들과 초기 요구사항 인터뷰 및 중간 검토 브리핑 진행
- **기술:** Java · Spring Boot · MySQL · AWS S3 · Docker

**[핵심 구현과 코드 보기](https://github.com/H-SeungWoo/Asset-Box#readme)**

### CHECK-ON — 교육 데이터 분석·상담 지원 서비스

학습 데이터를 분석해 학생의 위험 신호를 확인하고 상담을 지원하는 서비스입니다.

- **담당 역할:** Kafka–HTTP Adapter, 요청·결과 전달과 재시도·복구 흐름, 빌드·배포 환경
- **기술:** Java · Spring Boot · PostgreSQL · Kafka · Docker · GitHub Actions · AWS EC2

**[백엔드 구조와 배포 코드 보기](https://github.com/H-SeungWoo/CheckOn-backend#readme)**
